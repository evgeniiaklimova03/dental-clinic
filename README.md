# Стоматология «Белая Гавань» — премиальный сайт-визитка

Учебный проект для портфолио. Полноценный адаптивный сайт премиальной стоматологической клиники, созданный с нуля на чистых HTML, CSS и JavaScript.

## 🔗 Демо

- **Сайт:** [https://dental-clinic-mvvb.netlify.app/](https://dental-clinic-mvvb.netlify.app/)
- **Репозиторий:** [https://github.com/evgeniiaklimova03/dental-clinic](https://github.com/evgeniiaklimova03/dental-clinic)

## 🛠 Технологии

- **HTML5** — семантическая разметка, доступность (a11y).
- **CSS3** — Flexbox, Grid, кастомные свойства (переменные), медиа-запросы.
- **JavaScript (Vanilla)** — интерактивный слайдер «до/после», мобильное бургер-меню.
- **Git + GitHub** — контроль версий.
- **Netlify** — хостинг, автодеплой из GitHub.

## ✨ Что реализовано

- Адаптивная верстка (mobile-first, поддержка планшетов и десктопов).
- Секция «Услуги» с карточками.
- Блок «О клинике» с фото и списком преимуществ.
- Секция «Врачи» с карточками специалистов.
- **Интерактивный слайдер «До/После»** (перетаскивание мышью и тачем).
- **Форма записи** с валидацией и отправкой заявок через Formspree.
- Мобильное бургер-меню.
- SEO-мета-теги (Open Graph для соцсетей).
- Дизайн-система на CSS-переменных (цвета, шрифты).

## 🎨 Дизайн

- Палитра: тёплый премиум (шалфейный зелёный, кремовый, терракота).
- Шрифты: Playfair Display (заголовки) + Inter (текст).
- Все цвета и шрифты вынесены в CSS-переменные в `:root`.
